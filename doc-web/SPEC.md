# 文档阅读站

## 需求

- REQ-01：自动发现根目录及数字编号章节中的 README.md / readme.en.md，原文件作为唯一内容来源。
- REQ-02：桌面三栏：章节导航、正文、当前文章目录；小屏提供可展开菜单与目录。
- REQ-03：中文、英文、双语三种阅读模式，URL 可分享、刷新可恢复，记住语言偏好。双语按 Markdown 小节配对，宽屏并排、窄屏上下。
- REQ-04：以文字阅读为主，无营销首页、动画或外部字体；支持表格、代码高亮与复制、章节筛选、前后篇。
- REQ-05：代码置于 doc-web，生成纯静态 HTML，支持任意静态主机和子目录；自动构建产物，教程更新即可重建。

## Technical Spec

Node.js ESM 构建脚本使用 markdown-it 解析 Markdown，highlight.js 高亮。构建扫描仓库目录，不复制维护教程内容。为每篇生成 zh/en/both 三份 HTML，使用相对链接，在无 JavaScript 时仍可阅读和导航。双语按一级/二级标题分段，校验两语言的段落结构；结构不一致时分栏显示完整文章，避免漏掉内容。三级标题加入目录，各语言锚点唯一。Markdown 内部链接转换为站内页面；源码链接指向 GitHub。

轻量原生 JS 仅负责偏好、章节筛选、复制、移动菜单和滚动目录高亮。不请求第三方资源。CSS 使用系统字体、单语言约 760px 正文宽度，双语扩大宽度。默认首页为仓库概览，目录按编号自然排序。存储异常不影响阅读。

私有仓库的在线预览保持私有。根据追加需求：GitHub Actions 在 master 每次 push 时自动测试、构建并部署 Pages；Pull Request 只测试构建。Pages 需要首次配置，不改变仓库可见性。
